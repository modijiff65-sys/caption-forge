Install Kaise Karein

  1. Agar game me koi purana Unknown naam wala DragonVerse pack dikh raha hai, to Settings → Storage me jaakar use delete karo.
  2. Upar se DragonVerse Fixed (.mcaddon) download karo aur file ko Minecraft se kholo — "Successfully imported" aane do.
  3. Agar mcaddon se import na ho, to pehle BP phir RP mcpack alag-alag import karo — order yahi rakhna: pehle BP, phir RP.
  4. Apni world me dono DragonVerse packs ON karo, Cheats ON aur Beta APIs experiment bhi ON rakho.
  5. Game me chat me boss1 ya dragon1 likh kar test karo.
